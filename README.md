# Currency Watch

Приложение представляет собой RESTful API и реализует доступ к информации об изменении цен на отслеживаемые криптовалюты. Приложение собирает данные из CoinMarketCapAPI, сохраняя их в базу данных с помощью SQLite. Приложение обновляет данные об отслеживаемых криптовалютах каждую минуту.

Подробную `OpenAPI` спецификацию можно найти в файле `spec/openapi.yaml`.

## Запуск приложения

Для запуска приложения в production-среде лучше использовать `Node.js 26`. Необходимо установить переменные окружения, описанные в `.env.template`:

- `BEARER_TOKEN` &mdash; токен аутентификации, который необходимо добавлять в каждый запрос;
- `API_KEY` &mdash; ключ доступа к CoinMarketCapAPI, которые можно получить на сайте данной организации;
- `PORT` &mdash; порт, на котором будет доступен HTTP-сервер;
- `SQLITE_PATH` &mdash; пусть к базе данных SQLite.

Для установки всех зависимостей в `npm` можно выполнить:

```sh
npm install
```

Для локального запуска приложения стоит создать файл `.env`, в котором описать значения выше перечисленных переменных окружения, и затем запустить

```sh
npm run startDev
```

В режиме разработчика сервер будет работать на не защищённом шифрованием HTTP-протоколе. Приложение автоматически установит из `.env` файла все необходимые переменные окружения.

## Описание хореографии сервиса

Подробное описание можно найти в файле `spec/openapi.yaml`.

Все методы возвращают `application/json`, если аутентификация была успешной.

### GET /list

Возвращает список отслеживаемых криптовалют.

### POST /add

Параметры запроса:

- `id` &mdash; идентификатор криптовалюты на CoinMarketCapAPI.
- `symbol` &mdash; тикер криптовалюты (если не был передан её `id`).
- `load` &mdash; булево значение, означающее, произвести ли сразу после добавления криптовалюты загрузку её цены, по умолчанию `false`.

Добавляет криптовалюту в список отслеживаемых криптовалют.

### GET /info

Параметры запроса:

- `id` &mdash; идентификатор криптовалюты на CoinMarketCapAPI.
- `symbol` &mdash; тикер криптовалюты (если не был передан её `id`).

Возвращает информацию об отслеживаемой криптовалюте, включая её `id`, тикер и название.

### DELETE /remove-from-list

Параметры запроса:

- `id` &mdash; идентификатор криптовалюты на CoinMarketCapAPI.
- `symbol` &mdash; тикер криптовалюты (если не был передан её `id`).

Удаляет криптовалюту из списка отслеживаемых криптовалют, и возвращает `true`, если она была успешно удалена, и `false` если такая валюта не найдена. Также удаляет все записи об истории цен на данную криптовалюту.

### POST /load

Параметры запроса:

- `id` &mdash; идентификатор криптовалюты на CoinMarketCapAPI.
- `symbol` &mdash; тикер криптовалюты (если не был передан её `id`).

Подгружает с CoinMarketCapAPI информацию о текущей цене на данную криптовалюту и сохраняет в базу данных, также возвращая её в теле ответа.

### GET /price

Параметры запроса:

- `id` &mdash; идентификатор криптовалюты на CoinMarketCapAPI.
- `symbol` &mdash; тикер криптовалюты (если не был передан её `id`).
- `after` &mdash; время (предпочтительно в формате `ISO`), начиная с которого ищутся записи истории цен. По умолчанию не установлено.
- `until` &mdash; время, начиная с которого записи истории цен не ищутся. По умолчанию не установлено.
- `offset` &mdash; количество записей, которое нужно пропустить. По умолчанию `0`.
- `limit` &mdash; количество записей, возвращаемых в теле ответа. По умолчанию `1`.
- `asc` &mdash; булево значение, означающее порядок, в котором возвращаемые записи сортируются. По умолчанию `false` (по убыванию).

Возвращает список записей, содержащих время и значение цены нужной криптовалюты в это время.

### DELETE /erase

Параметры запроса такие же, как у `GET /price`.

Удаляет записи о цене указанной криптовалюты в указанный промежуток времени согласно запросу.
